# The Circle Academy – Digital Presence & Lead Generation

## About the Project

This is one of the projects I completed during my Business & Marketing Analytics training.

In this project, I reviewed the digital presence of The Circle Academy, an online CBSE Mathematics coaching brand for Grades 9–12. I studied the website, basic SEO, content and user experience, and then created a simple Wix landing page focused on free-demo enquiries.

## What I Worked On

- Reviewed the existing website and digital presence
- Checked design, UX, content and basic SEO areas
- Used Google PageSpeed Insights for performance review
- Suggested practical digital marketing improvements
- Created a Wix landing page for lead generation
- Added a clear CTA and enquiry form
- Checked the page on desktop and mobile

## Tools Used

- Wix
- Google PageSpeed Insights
- Basic SEO Review
- UX / Content Review

## What I Learned

This project helped me understand:

- How website design can affect conversion
- How SEO, content and UX work together
- How a landing page can support lead generation
- How to create a simple digital journey from awareness to enquiry
- How to review a website from a business and user point of view
